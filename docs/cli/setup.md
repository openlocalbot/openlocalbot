# `openlocalbot setup`

Initialize `~/.openlocalbot/openlocalbot.json` and the agent workspace.

Related:

- Getting started: [Getting started](/start/getting-started)
- Wizard: [Onboarding](/start/onboarding)

## Examples

```bash
openlocalbot setup
openlocalbot setup --workspace ~/.openlocalbot/workspace
```

To run the wizard via setup:

```bash
openlocalbot setup --wizard
```
